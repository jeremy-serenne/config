# Configuration personnelle

Ce dépôt permet de remettre une machine de travail en service avec un agent.

- Détecter l'OS avec `uname -s`. Sur macOS, lire [macos/AGENTS.md](macos/AGENTS.md).
- Linux et Windows ne sont pas encore pris en charge : arrêter avant toute installation et expliquer que leur setup reste à définir.
- Ne jamais versionner de secrets, sessions, clés privées, données de calendrier ou historiques personnels. Le dépôt est public.
- Préserver les fichiers existants et les changements locaux. Ne pas appliquer de nettoyage Homebrew.
- Le setup est une configuration personnelle ; les instructions professionnelles et les accès de l'entreprise se récupèrent séparément.
